# KaTrain

Go playing and teaching app, pinned to the source revision used for this package.
Includes its model, desktop launcher, and Nix-built KataGo.

Uses Python 3.12, stable Kivy 2.3.1, ffpyplayer, and KataGo 1.17.1 or newer.
The default KataGo backend uses OpenCL and needs a working host OpenCL driver.
An explicit engine path in existing KaTrain settings still takes precedence (F8).
